# Project Selection Boundary

- When the role is primarily centred on computer vision, use Automated Nematode Egg Detection as the only project evidence and omit StackRadar.
- When the role is primarily centred on LLMs and AI automation, use StackRadar as the only project evidence and omit Automated Nematode Egg Detection.
- The only exception is a role whose core responsibilities substantively include both computer vision and LLM-powered automation. For such a role, both projects may be included, but only when each project provides evidence for a core requirement and their inclusion still satisfies all other relevance, evidence-selection, structure, and length rules.

# Computer Vision / Applied Machine Learning

Use this strategy when the role mainly involves image analysis, object detection, model development, model evaluation, or deploying computer-vision solutions.

- In the opening, position Junwen as a recent master's graduate with hands-on experience applying computer vision to a real laboratory problem.
- Use Automated Nematode Egg Detection as the sole project evidence unless the role meets the explicit combined computer-vision-and-LLM-automation exception above. Select the verified project details that best match the job description.
- Focus on relevant technical work and practical outcomes. Use additional implementation details from the CV when they help address the job description.
- Show Junwen's interest in using computer vision to solve practical, real-world problems.
- Use Junwen's Tencent product experience only when problem understanding, user focus, requirements analysis, or collaboration with engineers is relevant.

# Applied AI / AI Automation

Use this strategy when the role mainly involves AI-powered workflows, automation, LLM applications, integrations, agents, or practical AI solutions.

- In the opening, position Junwen as a recent master's graduate with practical experience building AI-powered solutions that reduce manual work.
- When the job description is primarily centred on LLMs and AI automation, use StackRadar as the sole project evidence unless the role meets the explicit combined computer-vision-and-LLM-automation exception above. Focus the StackRadar discussion on its two LLM-powered workflows: screening newly posted jobs for suitability and drafting tailored cover letters.
- For broader applied-AI roles that are not primarily centred on LLMs, consider Automated Nematode Egg Detection as additional evidence only when it directly matches a core requirement.
- Focus on how Junwen understood a manual or repetitive workflow, identified where AI could help, designed and implemented an AI-supported solution, evaluated its performance, and turned it into a usable result.
- Emphasize verified practical outcomes rather than presenting the projects only as technical exercises.
- Use his Tencent product experience as supporting evidence for problem understanding, user focus, requirements analysis, and collaboration with AI engineers.
- Connect the role to his long-term goal of becoming a well-rounded AI solution builder who can take practical AI solutions from idea and design through implementation, evaluation, and delivery.
